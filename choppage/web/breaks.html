CHOPPAGE breaks

Load drum breaks into an M-VAVE FM-1 running CHOPPAGE, over the USB cable. Chrome or Edge (WebMIDI with SysEx); close anything else using the FM-1's MIDI port first. Up to 8 breaks, 252 KB in all: a two-bar break at 22 kHz is about 75 KB.

Drop a break here (WAV, AIFF, MP3, FLAC, ...) or click to choose a file

The FM-1 cuts each break into slices and tags them (kick, snare, hat, ghost) when it arrives; EDIT on the FM-1 changes both. CHOPPAGE is free software (GPL-3.0), built on Felucca by Leo Kuroshita (Hügelton Instruments). M-VAVE and FM-1 are trademarks of their owners.
